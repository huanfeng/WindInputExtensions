# 扩展程序模板

`python/` 是最小可运行的扩展：声明要收按键类别，每收到一个按键就写一行日志。

用法：

1. 复制 `python/` 整个目录，目录名就是扩展 id，放进输入法用户数据目录的 `extensions\`；
2. 改 `extension.toml` 里的名字、授权档位、启动方式；
3. 在设置 → 高级 → 扩展程序里启用。
